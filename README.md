# Анализ больших данных: Паттерны правонарушений при эксплуатации систем видеонаблюдения в школах

Данный репозиторий содержит полный пайплайн исследования судебной практики по вопросам видеонаблюдения в общеобразовательных учреждениях РФ. Проект охватывает этапы от веб-скрейпинга открытых реестров до построения предиктивных моделей машинного обучения и интерактивных BI-дашбордов.

**Тема проекта:** «Паттерны правонарушений при эксплуатации систем видеонаблюдения в школах: сравнительный анализ данных открытых реестров по ключевым регионам РФ».

## Используемые технологии
*   **Языки:** R, Python (вспомогательные скрипты. Были использованы для тестирования до того, как начать полноценный парсинг через R).
*   **Парсинг и ETL:** `rvest`, `chromote` (headless-браузер), `BeautifulSoup` (использовался для теста), регулярные выражения (Regex).
*   **Анализ данных и ML:** `tidyverse` (`dplyr`, `tidyr`, `stringr`), `randomForest`.
*   **Визуализация и BI:** `ggplot2`, Power BI Desktop, `Shiny`, `DT`.
